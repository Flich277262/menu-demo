# 0xC0FFEE · 為了自由喝咖啡

8-bit 掌機 RPG 風格的咖啡廳菜單，純靜態網站（單一 `index.html`，無需建置）。

- 品名以 UTF-8 十六進制呈現，中文／English 以小字補充；價格亦以十六進制標示
- 右上選單切換分頁：咖啡、茶類、蛋糕、輕食（網址 `#coffee` `#tea` `#cake` `#light` 可直接開啟指定分頁）
- 彩蛋：3 秒內連點對話框 5 次解鎖隱藏菜單
- 響應式版面（RWD）：手機、平板、桌機自動適配，最窄支援 320px

直接用瀏覽器開啟 `index.html` 即可。字體使用 Google Fonts（Press Start 2P、DotGothic16），需連網載入。
